Windows 10 or 11, 64-bit

Download SurfaceCast

An installer and a portable zip, with nothing else to install - the Python runtime and the video decoder go inside the build.

Every release carries a SHA256SUMS.txt to check the downloads against, and the complete source for that exact version.

Get the latest release Read the guide first

Windows will warn you about this download, and it is right to. The build is not signed with a code signing certificate, so SmartScreen shows "Windows protected your PC". Choose More info and then Run anyway, or check the download against SHA256SUMS.txt first - that tells you the file is the one that was published, which is the thing a signature would be telling you. Some managed machines refuse unsigned installers outright; the portable zip can be copied into place without an installer at all.

What is in a release

Installer

SurfaceCast-<version>-setup.exe. Start menu entry, file associations for scenes and shows, and an uninstaller.

Portable zip

SurfaceCast-<version>-portable.zip. Unpack and run - nothing is written outside the folder except the settings file. For a machine you cannot install on.

Source

SurfaceCast-<version>-source.zip. The complete corresponding source for that build, which the licence entitles you to and which is published beside it rather than on request.

Checksums

SHA256SUMS.txt. Run Get-FileHash <file> -Algorithm SHA256 in PowerShell and compare.

What you will need

A second screen

Set the projector as an extended display, not a mirrored one. Win+P → Extend.

Something to project onto

The demo scene needs no media at all, so you can check the output before finding any.

What it costs, and what would help

SurfaceCast is published under the GNU General Public License v3 or later, so anyone you hand a build to gets the source and the same freedom to change it. It is built by Dispatch Dataworks.

Two things would help more than money would:

Tell us what you want to project on

The page on who it is for is written from guesswork about who needs software like this. One note about the room, the surface and what you are trying to do is worth more than a donation would be, because it is what the next release gets shaped by. Write to help@surfacecast.app.

Say what broke

There is no update checker and the program never contacts us, so a fault on your projector is invisible here unless you say so. The version is under Help > About; send that with what happened.

No donate button. If you want it set up for a venue, or a fixture profile written for lights that came with no specs, write to help@surfacecast.app and we will talk. That is the question worth answering before anything here carries a price; a tip jar is not.
