Not released yet

Download SurfaceCast

There is no public build yet. When there is, it will be Windows 10 or 11, 64-bit, with nothing else to install - the Python runtime and the video decoder go inside the build.

The first build is not out. When it is, it will be an installer and a portable zip, from this site, with a SHA256SUMS.txt to check them against. Write to help@surfacecast.app and you will be told when - the program has no update checker and never contacts us, so it cannot tell you itself.

What you will need

A second screen

Set the projector as an extended display, not a mirrored one. Win+P → Extend.

Something to project onto

The demo scene needs no media at all, so you can check the output before finding any.

What it costs, and what would help

SurfaceCast is published under the GNU General Public License v3 or later, so anyone you hand a build to gets the source and the same freedom to change it. It is built by Dispatch Dataworks.

Two things would help more than money would:

Tell us what you want to project on

The page on who it is for is written from guesswork about who needs software like this. One note about the room, the surface and what you are trying to do is worth more than a donation would be, because it is what the first release gets shaped by. Write to help@surfacecast.app.

Nothing to pay, and no donate button

Money is not what the project is short of at this stage, and a tip jar for software nobody can download yet would be worse than none.

Not for sale yet. If you want it set up for a venue, or a fixture profile written for lights that came with no specs, write to help@surfacecast.app and we will talk. That is the question worth answering before anything here carries a price; a tip jar is not.
