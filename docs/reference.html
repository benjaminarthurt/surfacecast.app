SurfaceCast reference

Every screen and every control, as a lookup. If you want to be taught how to run a show, read the user guide instead — this is the thing to reach for when you are in front of the application and want to know what one particular box does.

Ranges and limits below are the ones the application enforces.

The control panel

The main window. Five regions:

Region What it is
Layers (left dock) The object stack for the scene being edited, and the buttons that add objects. Closable; View ▸ Panels ▸ Layers brings it back.
Preview (center) The scene being edited, with editing overlays. Not the output.
Properties (right dock) Everything about the selected object. Closable, same as Layers.
Scene strip (bottom) One slot per scene, with the cue settings under each.
Status bar Show timer, remote, lights, projector, and a message line.

Status bar

Read right to left, these are permanent indicators rather than messages:

Indicator Meaning
Show timer Counts down the active scene when the timer is running; blank when it is not.
Remote The address the remote is serving on, and the last device that used it. Blank when off.
Lights Lights: n — how many LEDs or fixtures are being driven. Lights: ! means switched on but not sending; the tooltip says why. Blank when off.
Projector Which screen the output window is on, or Projector: closed.

Layers panel

The object stack for the scene being edited. Index 0 is the top — the first row is drawn over everything below it, which is how the list reads on screen.

Add buttons: Video, Image, Color, Mask, Mesh image, Mesh video.

Then Raise and Lower (arrow buttons), Duplicate, Delete, Aim.

Each row shows the object's name and a one-line summary of what it is. The footer counts objects against the 32 limit.

Properties panel

Everything about the selected object. The first group is the same for every type; the rest depend on what it is.

Object (every type)

Control Range What it does
Type What this object is. Not editable.
Name What it is called in the layer list.
Visible Untick to hide it without deleting it.
Locked Stops it being dragged in the preview.
Opacity 0–1
Vignette 0–1 Fades the object's edges to transparent, so it settles into the surface instead of ending on it. 0 is off.
Shape Edge feather · Radial Edge feather keeps the center at full brightness and fades only the borders. Radial fades outwards from the center.
Show an alignment grid instead of content Aiming mode. Replaces this object's content with a grid on the output. Never saved — a show reopening with grids on stage would be a nasty surprise.

Transform (every type)

Control Range What it does
Rect — X, Y, W, H % of canvas Placement, as a share of the canvas rather than in pixels, so a show survives a change of projector.
Rotation −180° to +180° About the rectangle's center, in pixel space, so 45° looks like 45° on a non-square canvas.
Pixels The resulting size and position in output pixels, and the canvas size. Not editable.
Keystone Whether a corner pin is applied. Not editable.
Fill output Sets the rectangle to the whole canvas.
Center Centers it without changing its size.
Reset keystone Clears the corner pin, leaving the rectangle alone.

Mask

A mask paints over whatever is beneath it, so it blanks spill off something that should stay dark.

Control Range What it does
Shape Rectangle · Ellipse · Polygon
Invert (mask everything outside the shape) Turns the mask inside out: the shape becomes the hole.
Feather 0–1 Softens the mask edge.
Corner radius 0–1 Rectangle only.
Color What the mask paints. Black for blanking; anything else is a flag.
Points 3–16 sides Build regular polygon replaces the points with an even-sided shape. Polygon only.

Mesh (mesh image and mesh video)

Control Range What it does
Cells 1–16 each way How finely the surface is divided. More cells fit a curve better and cost more to draw.
Flatten the grid Throws the warp away and leaves a flat rectangle.

Pull a mesh point with W and drag. Tab steps between points; Alt+arrows nudge the lit one, and Ctrl makes the nudge ten times coarser, not finer.

The scene strip

One slot per scene, 1–9 on the keyboard for the first nine.

Left click takes a scene live straight away. Ctrl+left click loads its media and opens it for editing without changing the output. Right click, or press and hold on a touch screen, opens the scene menu; a middle click does the same on a mouse that has the button.

The number keys work the other way round: 1-9 queue a scene, and a second press — or Space — takes it.

Each slot shows its number, name, status, object count and whether it holds media. The status reads LIVE, Ready, Loaded or empty.

Under each slot, unless View ▸ Cue settings on the scene strip is off:

Control What it does
hold / duration How long the show timer holds this scene. hold means stop here.
Cut / Fade How the scene arrives when taken.
seconds How long the fade takes. Grayed out on a cut, but the value is kept.

Arrows appear at the ends when there are more scenes than fit; the strip scrolls sideways.

The scene menu (right click)

Take live · Queue · Load media · Edit · New scene here · Open scene here… · Save this scene… · Rename… · Copy to scene ▸ · Duration… · Background… · Lights… · Notes… · Transition ▸ (Cut, Fade, Fade time…) · Move this scene left / right · Unload media · Clear slot.

The heading names which scene the menu is about, and Lights… shows that scene's cue, so the strip reads like a cue sheet.

The preview

The scene being edited, which is not always the scene on air — the header says EDIT — NOT LIVE when they differ.

  • Drag an object to move it. Handles appear in layout mode (L).
  • Keystone mode (W) drags the four corners instead.
  • Arrows nudge by one output pixel, Shift+arrows by ten.
  • Page Up / Page Down rotate.
  • The alignment grid (G) and safe-area guides are drawn here only, never on the output.

The projector window

Borderless, fullscreen, no cursor. It is a second view onto the same scene the preview shows, minus the editing overlays.

  • F5 opens and closes it; Esc closes it from the window itself.
  • Keys pressed here are forwarded to the control panel, so shortcuts work from either window.
  • Anything past the canvas edge is masked black, so an object dragged off the side cannot throw light onto whatever is beside the surface.
  • With nothing live it says so rather than going quietly black — that is how you tell an unassigned output from a dead cable.

Settings

File ▸ Settings, Ctrl+,. Five tabs. The window is capped to the screen's height and each page scrolls, so the OK and Cancel buttons are always reachable.

Files

Two groups: Autosave and recovery, and Media folder.

Control Range What it does
Keep a recovery copy while work is unsaved On by default. The only thing between a crash and hours of rig work.
Every 15–900 s How often the recovery copy is written.
File Where that copy lives. Not editable.
Folder The media folder. Browse… picks one, Open shows it in the file manager. Empty means the default.

Remote

Control Range What it does
Control the show from a phone or tablet Off by default, and it has no password.
Network Which adapter to listen on. Includes a this computer only entry.
Port 1024–65535 50505 unless changed, and it does not move on its own. Use default puts it back.
Address The address to type into the phone. Not editable.
Allow editing scenes from the remote On. Untick once a rig is aligned — there is no undo for a mis-drag from a phone.
Allow uploading media from the remote Off by default, and separate from editing: everything else the remote does stays inside the show, while this writes files onto this machine.

Lights

One group, Practical lights (WLED). The rig itself is not here — zones are aimed against the picture, so they live under Output ▸ Light zones. This page is what stays the same whatever the rig looks like.

Control Range What it does
Send the projected colors to a light controller Off by default.
Controller The WLED controller's address, as shown on its own web page.
Port 1–65535 21324, WLED's realtime port. Not the port its web page is on. Use default puts it back.
Refresh 10–60 per second How often the lights are updated. 30 is smooth and costs about a hundredth of a core.
Saturation 0.00–2.00 How far the sampled colors are pushed from gray before they are sent. An average over a region is always paler than the region looks, so a rig following a picture usually wants more than 1 — about 1.5 turns a soft green into a clear one. Brightness does not change, and white, black and gray pass through untouched, so a highlight stays white. At 0 the lamps follow brightness with no color. Applies to every lamp, WLED and DMX alike.

Light zones

Output ▸ Light zones. The rig: where the lamps are and where their colors go. Kept with this computer, not in the show file.

The picture on the left is the live output with the zones drawn on it, each filled with the color it is currently sending. Drag a zone to move it, drag the square in its bottom-right corner to resize.

Controller

Control Range What it does
Send to the lights Same switch as Output ▸ Lights follow the output.
Address The WLED controller. One controller, named outright — SurfaceCast does not broadcast.
Port 1–65535 21324 by default.
Refresh 10–60 per second
DMX Off · Art-Net · sACN / E1.31 · USB adapter How DMX zones leave the machine.
Node Art-Net: the node's address, required. sACN: empty multicasts, which reaches only nodes patched to the universe.
Adapter USB only. The serial port, named with what it reports itself as. Rescan looks again. A port that is set up but missing shows as (not connected).
Carries universe 1–63999 USB only. A widget has one DMX line, so it sends this universe and nothing else.
Fixtures… Fixtures.

Build a layout

Both replace every zone.

Control Range What it does
Grid 1–64 × 1–64 A rectangle of zones, numbered left to right then top to bottom. A strip along one edge is a grid one row deep.
Edges 1–64 a side A ring round the border, clockwise from the top left — how ambient strip is usually hung.

Zones

Add, Duplicate, Remove, Clear, then for the selected zone:

Control Range What it does
Name
Left · Top · Width · Height % of canvas The rectangle this zone averages.
Goes to WLED strip · DMX fixture Which rig this zone drives.
First LED 1–4096 WLED only. Counts from 1, the way WLED's own segment editor does.
Universe 1–63999 DMX only.
Channel 1–512 DMX only. The fixture's first channel, counting from 1.
Fixture DMX only. Which profile lays the color out.
How many 1–4096 How many LEDs, or how many fixtures in a row, take this color.
Wiring Rows, left to right / Rows, folded back each row / Columns, top to bottom / Columns, folded back each column / Reverse what it is now With Renumber, hands out pixel indices in the order the strip was actually run. For a rig of one-pixel zones from Grid or Edges, which put the zones in the right places and number them one particular way. Zones keep their places and their list order; only First LED changes.
Run direction One color across the run / Left to right / Right to left / Top to bottom / Bottom to top Which way this zone's pixels travel across its rectangle. One color averages the whole rectangle and gives every pixel the same color — what a wash wants, and what every rig did before this existed. The four directions divide the rectangle into as many slices as there are pixels, so each reads its own part of the picture; the name says where the first pixel sits.
Gain 0.0–4.0 Brightens or dims this zone alone. A practical next to a projected wash usually wants less than the picture. Brightness only: above the point where the brightest channel reaches full, the color stops changing rather than fading towards white.

A rig drives at most 4096 LEDs.

Scene light cue

The scene's right-click menu, Lights…. What this scene tells the lamps to do. Saved in the scene file, so it travels with the show.

The picture is that scene's own output, not whatever is on air. Zones can be clicked to select one, but not dragged — moving a zone is a change to the venue's rig, and doing it from inside a scene would be a trap.

Three groups: In this scene the lights (the three modes), Level, and Held colors.

Control Range What it does
Follow the picture Colors come off the projection. The default, and what a scene with no cue reads as.
Hold a color The lamps sit still whatever the picture does.
Stay dark Dark for this scene only, without blacking the projector out.
Intensity 0–200 % This scene's level, on top of each zone's gain. Multiplies with it, and like gain it changes brightness without changing the color.
One color for every zone One color is also what survives moving to a venue whose rig has a different number of zones.
Pick a color… Sets the held color — for the selected zone, or for all of them.
Use what is on screen now Freezes what the zones are reading off this scene. Usually the quickest way to author a hold.

A cue arrives over the scene's own transition time, so a three second fade moves the lamps over three seconds.

Fixtures

Output ▸ Light zones ▸ Fixtures…. How a kind of lamp lays its channels out.

Two are built in and cannot be edited:

Profile Channels
RGB (3 channels) red, green, blue
Dimmer + RGB (4 channels) dimmer (held at full), red, green, blue

The four-channel one is the one that catches people out: send a four-channel par three channels and it stays dark however right the color is.

Fixtures

Add (starts from dimmer + RGB), Copy, Remove, and a name field. Renaming takes any zone using it along too. Removing one leaves zones that named it falling back to plain RGB — lit wrongly rather than silently stopped.

Channels

Control Range What it does
How many channels 1–64 The fixture's DMX footprint.
Channel n role Red · Green · Blue · Dimmer (held) · Hold a value Red, green and blue follow the picture. Everything else is held where you put it.
Channel n value 0–255 For held roles only; grayed out on a driven channel.

There is no white or amber role. Mixing those well is a per-fixture judgement, so they are held channels set to whatever suits.

Find a channel

How to describe a lamp whose manual you do not have. It sends live.

Control Range What it does
Patched at — Universe / First channel 1–63999 / 1–512 Where the fixture is.
Sweep channel 1–64 Sends that one channel with every other channel at zero, so whatever moves is that channel.
(slider) 0–255 The value being swept.
Send now Starts sending. Unticking sends a blackout, so the lamp does not stay stuck.
Test color… With Sweep off, the whole fixture is sent this color — how you check a profile once it is built.

Help and document windows

F1 opens the help window: three tabs — Getting started, Keyboard, Mouse. It is modeless, so it can stay open while you work. The menu shortcuts it lists are read from the menus themselves, so they cannot fall out of step with the application.

The Help menu also opens each bundled document in a reader window with a chooser at the top, so an installed copy carries its own documentation and needs nothing registered for .md files. Open the folder shows the same files on disk.

The phone remote

A web page on the local network. Off by default and it has no password — see Settings ▸ Remote.

Control What it does
Scene buttons Tap to queue, tap again to take — the same rule as the number keys.
TAKE QUEUED Same as Space on the console.
BLACKOUT
SHOW TIMER Start and stop.
Edit mode A switch. With it on, tapping a scene opens its objects instead of queueing it. Opening a scene to edit never puts it on air.
Media Opens the media folder page.

In edit mode: undo and redo, the scene's Active for time and Transition, an arrow pad with move / size / rotate / keystone modes, corner buttons for the keystone, and the common object properties.

The Media page lists what is in the media folder. Add photos or video appears only when uploading is allowed in settings; it is off by default.

Phone edits go on the same undo stack as the console's, so either end can take back what the other did.
