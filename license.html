Getting the source

The GPL entitles anyone who receives SurfaceCast — including as a packaged Windows build — to the complete corresponding source code for the version they received.

The source is not published on a public site. It is supplied on request, at no charge: write to help@surfacecast.app, saying which version you have, and you will be sent the complete corresponding source for exactly that version.

The installed build reports its version under Help > About, and the Windows executable carries it in its file properties.

Qt, via PySide6 (LGPL v3)

A packaged SurfaceCast bundles the Qt libraries and the PySide6 bindings. Both are used here under the GNU Lesser General Public License, version 3, which is compatible with the GPL that covers SurfaceCast itself.

  • Qt is copyright The Qt Company Ltd and other contributors.
  • Licence text: https://www.gnu.org/licenses/lgpl-3.0.html
  • Qt's own licensing page: https://doc.qt.io/qt-6/lgpl.html
  • Source for the exact version used is published by the Qt Project at https://download.qt.io/official_releases/qt/ and by PySide6 on PyPI at https://pypi.org/project/PySide6/. The version in this build is shown in the diagnostics report (Help > Save diagnostics report).

SurfaceCast does not modify Qt. It is bundled unmodified and loaded as a shared library.

Replacing the Qt libraries. The LGPL gives you the right to run SurfaceCast against your own build of Qt. SurfaceCast is deliberately packaged as a folder of loose files rather than a single self-extracting executable, so this needs no cooperation from us: the Qt DLLs sit next to SurfaceCast.exe in the install directory and can be replaced in place with a compatible build.

FFmpeg

Video decoding uses the FFmpeg build that Qt bundles with its multimedia backend. It is redistributed as Qt ships it, under the LGPL v2.1 or later.
